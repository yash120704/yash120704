<br/>

> **Production-grade multi-model ensemble for real-time industrial anomaly detection**

| | |
|---|---|
| **Stack** | Python · Scikit-learn · Django · Streamlit · WebSockets |
| **Dataset** | 40,000 samples · 12 sensor features |
| **Models** | 4 Autoencoders + OC-SVM + Mahalanobis = 10-model ensemble |

**🔑 Key Highlights:**

- 📡 Integrated **WebSocket streaming** for live sensor data ingestion and alerting
- 📊 Built an interactive **Streamlit dashboard** for real-time monitoring and anomaly visualization
- ⚡ Engineered a fusion scoring layer combining multiple anomaly signals into a unified decision boundary

```
[Sensor Stream] → Kalman Filter → Autoencoder → Mahalanobis → OC-SVM → L2 Fusion → Alert
```
